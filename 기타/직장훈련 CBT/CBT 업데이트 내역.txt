2. 현재 지휘,진압,구조,구급 4파트이지만 + 기동파트도 추가예정

[업데이트 필요성]

1. 로그인 시 소속 정보 표시 강화
-> 현재는 "OO님 환영합니다!"만 표시됩니다.
-> 소속 정보를 포함한 환영 메시지 필요
  - 예: "[용산소방서 후암119안전센터] OO님 환영합니다!"
2. 관리자 페이지 기간별 데이터 관리 기능
-> 현재는 전체 시험 결과가 기간 구분 없이 누적되어 표시됩니다.
-> 기간별 조회 및 다운로드 기능
    예: 2026년 상반기, 2026년 하반기, 2027년 상반기 등

---------------------------------------------------------

3. 기간별 데이터 관리 구체화

  상/하반기 자동 구분으로 결정하셨는데:
  - 조회 UI: 드롭다운으로 "2026년 상반기", "2026년 하반기" 등 선택
  - 다운로드: 기간별로 엑셀 파일 다운로드
  - 통계: 기간별 통계 (참여 인원, 평균 점수 등)

 6. 소속별 통계 기능 강화

  관리자/담당자가 필요할 만한 통계:
  - 소방서별 평균 점수
  - 안전센터별 참여율
  - 직무별 합격률 (70점 이상)
  - 기간별 성적 추이 그래프

7. 알림/공지 기능

  - 시험 기간 시작/종료 알림
  - 담당자용 미응시자 현황
  - 성적 발표 알림

2. 기간별 데이터 관리: 상/하반기 자동 구분, 기간별 조회/다운로드
